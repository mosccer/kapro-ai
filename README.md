# Kapro AI

คู่มือสำหรับตรวจสอบว่าโมเดล Kapro AI แต่ละเวอร์ชันใช้กับเครื่องและโปรแกรมใดได้บ้าง

## เลือกวิธีรันจากชนิดไฟล์

| ชนิดไฟล์ | โปรแกรมและเครื่องที่ใช้ |
| --- | --- |
| `.gguf` | ใช้ `llama.cpp` หรือ Ollama เมื่อรองรับสถาปัตยกรรมของโมเดล เหมาะกับพีซี Windows/Linux หรือ Mac ที่มีหน่วยความจำพอ |
| `.safetensors` | ใช้ Python และ Transformers เมื่อมีไฟล์ config/tokenizer และรองรับสถาปัตยกรรมของโมเดล ถ้าเป็น LoRA adapter ต้องใช้โมเดลฐานที่ตรงรุ่นด้วย |
| `Modelfile` | ใช้กับ Ollama ต้องตรวจบรรทัด `FROM` ว่าต้องดาวน์โหลดโมเดลฐานหรือเตรียมไฟล์ใดไว้บนเครื่อง |

## การเลือกเครื่อง

- **พีซี Windows หรือ Linux** รันบน CPU ได้เมื่อโปรแกรมรองรับและ RAM พอ การใช้ GPU ขึ้นอยู่กับไดรเวอร์ โปรแกรม และ VRAM
- **Mac ชิป Apple Silicon** ใช้หน่วยความจำร่วมของเครื่อง ควรเผื่อพื้นที่ให้ระบบและโปรแกรมอื่นด้วย
- **เครื่องที่ RAM จำกัด** ดูขนาด weights และเผื่อหน่วยความจำสำหรับ context และ runtime ขนาดไฟล์เพียงอย่างเดียวใช้สรุปสเปกขั้นต่ำไม่ได้

## เริ่มใช้งานเมื่อมีไฟล์จริง

ถ้ามี `Modelfile` ที่อ้างอิงโมเดลได้ถูกต้อง ให้เปิดเทอร์มินัลในโฟลเดอร์นั้นแล้วรัน

```sh
ollama create kapro-ai -f Modelfile
ollama run kapro-ai
```

ตอนนี้คู่มือระบุความเข้ากันได้ตามชนิดไฟล์ ยังไม่มีผลทดสอบหรือสเปกขั้นต่ำที่ยืนยันสำหรับ Kapro AI แต่ละเวอร์ชัน
